# Real Windows sounds

Put the real sound files here and the Windows games use them automatically.
Nothing else needs changing. Any of `.mp3`, `.wav`, `.ogg` or `.m4a` works.

| File | When it plays | Where to get it on a Windows 11 PC |
|---|---|---|
| `startup.mp3` (or .wav) | When the desktop appears after booting, and after setup finishes | The Windows 11 startup sound is not a plain file on Windows; it is built into the system. Save a copy of the Windows 11 startup sound as `startup.mp3` (a recording, or an export from a tool like Resource Hacker on `C:\Windows\System32\imageres.dll`). |
| `volume.wav` (or .mp3) | When you let go of the volume slider | Copy `C:\Windows\Media\Windows Background.wav` here and rename it `volume.wav`. That is the ding Windows 11 plays when you move the volume slider. |

The sounds are Microsoft's, which is why they are not included in this repository.
